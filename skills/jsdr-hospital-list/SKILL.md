# jsdr-hospital-list: 병원 리스트업과 리서치

영업 담당자가 전화할 병원 목록을 만들고 관리한다. 결과물은 언제나 구글 드라이브 `JSDR/05 병원 리스트/` 의 구글 시트 "JSDR 병원 리스트" 하나다. 새 파일을 만들지 않고 그 시트에 더한다.
도구는 `~/Projects/jsdr-studio/tools/hospital_list.py` (표준 라이브러리만, `/usr/bin/python3` 로 돈다).

## 시트 구조

한 병원 한 줄, 한 통화 한 줄. 병합 셀, 빈 줄, 날짜 제목 줄을 쓰지 않는다. 그래야 필터, 정렬, 피벗이 된다.

**병원 마스터** (지점 하나가 한 줄)

| 열 | 채우는 법 |
|---|---|
| 병원 ID | H0001 꼴. 한 번 준 번호는 바꾸지 않고, 새 병원은 마지막 번호 다음 |
| 병원명 | 담당자가 적은 이름 (오타만 고침) |
| 브랜드 | 간판 유형, 지점, 지역 낱말을 뗀 이름. 체인 묶기에 쓴다 |
| 간판 유형 | 피부과 전문, 성형외과 전문, 일반 의원, 미표기. 등록명에서 읽는다 |
| 진료과 (카카오) | 카카오맵 업종 (피부과, 성형외과, 일반의원) |
| 지역 | 담당자가 쓰는 상권 이름 (강남, 압구정, 동탄) |
| 주소 | 도로명 주소 + (건물, 층). 지역 바로 옆 칸 |
| 시도, 시군구, 권역 | 주소에서 뽑는다. 권역은 서울 강남권, 서울 도심 서북권, 서울 서남권, 서울 동북권, 인천, 경기 남부, 경기 북부, 충청 세종 대전, 기타 지방 |
| 대표 전화 | 카카오맵에 올라 있는 번호 |
| 시트 기재 전화 | 담당자가 적은 번호 (네이버 0507 안심번호가 많다) |
| 전화 유형 | 안심번호 (0507), 지역번호, 대표번호 |
| 홈페이지, 카카오맵 | 링크 |
| 주소 확인 | 전화 일치, 이름 일치, 확인 필요, 미확인 |
| 카카오 등록명 | 맞게 찾았는지 눈으로 볼 때 쓴다 |
| 컨택 횟수, 첫 컨택, 최근 컨택, 담당자, 지점 수 | 수식. 컨택 로그에서 센다. 손으로 적지 않는다 |
| 메모 | 진료 시작 시각, 다른 번호, 다른 표기 |

**컨택 로그** (통화 하나가 한 줄): 날짜, 담당자, 순번, 병원 ID, 병원명 (기재), 지역 (기재), 전화 (기재), 메모, 원본 위치.
**담당자**: 이름, 연락처, 건수 (수식).
**요약**: 권역, 간판 유형, 담당자, 월별 집계 (수식).
**정리 기록**: 원본에서 고친 것 (오타, 밀린 칸, 표기).

간판 유형을 나누는 까닭: 간판에 "○○피부과의원", "○○성형외과의원" 이라고 과목을 이름에 붙여 쓸 수 있는 곳은 그 과 전문의가 연 곳이다. "○○의원" 은 일반의나 다른 과 전문의가 미용 진료를 하는 곳이 많다. 영업 말이 달라지므로 따로 본다. 카카오 업종은 "○○의원" 도 피부과로 나오는 일이 많아 이것만으로는 못 가린다.

## 1. 새 병원 리스트업 (지역이나 조건을 받았을 때)

1. 시트의 병원 마스터를 읽어 CSV 로 내려 둔다 (열 이름 그대로). 이미 있는 곳을 빼는 데 쓴다.
2. 후보를 모은다.

       /usr/bin/python3 tools/hospital_list.py find "동탄" --kind 피부과,성형외과,의원 --pages 3 --known master.csv > new.csv

   지역은 상권 이름(압구정, 홍대)이나 시군구(화성시) 어느 쪽도 된다. 한 쪽이 15곳, 쪽 수는 많아야 5. 넓은 지역(강남)은 상권으로 쪼개서 여러 번 돌린다.
3. 결과를 읽고 미용 진료와 상관없는 곳(내과, 정형외과 간판, 한의원, 치과)을 뺀다. 애매하면 남기고 메모에 적는다.
4. 대표님이나 담당자에게 몇 곳인지, 어느 권역인지 표로 보이고, 시트 병원 마스터 아래에 더한다. 병원 ID 는 마지막 번호 다음부터.
5. 담당자에게 나눠 줄 때는 컨택 로그에 미리 적지 않는다. 로그는 실제로 전화한 것만.

## 2. 이름만 있는 목록에 주소 채우기

    /usr/bin/python3 tools/hospital_list.py enrich in.csv out.csv      # 열: 병원명, 지역, 전화
    /usr/bin/python3 tools/hospital_list.py lookup "오라클피부과" "인천" --tel 032-566-5595

- 한 곳에 0.6초씩 쉬며 조회한다. 1,000곳이면 20분쯤 걸리니 백그라운드로 돌린다.
- 고르는 차례: 전화가 같은 곳, 이름이 같고 안심번호와 끝 네 자리가 같은 곳, 이름이 같고 그 지역에 있는 곳. 그래도 여럿이면 "확인 필요".
- "확인 필요" 와 "미확인" 은 그대로 두지 않는다. 카카오 등록명과 주소를 보고 맞으면 "이름 일치" 로 바꾸고, 아니면 네이버 지도나 병원 홈페이지에서 찾아 고친다. 못 찾은 곳은 폐업이나 이름 바뀜일 수 있으니 메모에 적는다.
- 주소를 지어내지 않는다. 못 찾으면 빈칸과 "미확인".

## 3. 옛 양식 옮기기 (직원 탭, 날짜 블록)

담당자 엑셀은 이렇게 생겼다: 탭이 담당자, B열에 날짜(261001 꼴) 한 줄, 그 아래 열 줄에 순번, 담당자(병합), 연락처(병합), 병원명, 지역, 전화.

1. 날짜 줄을 만나면 날짜를 기억하고, 병원 줄마다 날짜와 담당자를 붙여 한 줄로 편다. 병합 셀은 풀어서 줄마다 채운다.
2. 고치는 것은 표기뿐이다: 칸이 밀린 줄, 뻔한 오타(의언, 며동), 전화 표기(02.3015.5300), 전화 칸에 붙은 말("9시 시작" 은 메모로). 고친 것은 전부 정리 기록 탭에 남긴다.
3. 같은 병원이 여러 번, 여러 담당자에게 나오면 마스터에는 한 줄, 로그에는 나온 만큼. 같은 병원인지는 카카오 장소 ID 로 가린다 (이름 표기가 달라도 같은 곳으로 묶인다).
4. 날짜 줄에만 적힌 말("완료 (광주출장)")은 정리 기록으로.

## 4. 구글 시트에 쓰기

- 드라이브와 시트 커넥터로 쓴다 (jkim@aistorians.com). 처음 만들 때만 xlsx 를 올려 변환하고, 그 뒤로는 같은 시트에 줄을 더한다. 링크가 바뀌면 안 된다.
- 전화와 병원 ID 는 글자로 넣는다 (앞자리 0 이 사라지지 않게 작은따옴표를 앞에).
- 센 값(횟수, 최근 컨택, 집계)은 수식으로 둔다. 로그에 줄이 늘면 저절로 따라온다.
- 쓰고 나서 다시 읽어 줄 수, 수식 오류(#REF!, #N/A), 병원 ID 가 로그와 마스터에서 맞는지 본다.

## 지킬 것

- 담당자 휴대전화는 시트의 담당자 탭에만 둔다. 저장소, 스킬, 보고 글에 옮겨 적지 않는다.
- 조회는 공개된 사업장 정보(상호, 주소, 대표 전화)만. 원장 개인 번호나 개인 정보는 모으지 않는다.
- 조회 속도를 올리지 않는다 (동시에 셋까지). `KAKAO_REST_KEY` 가 있으면 공식 로컬 API 를 쓴다.
- 메일, 문자, 전화 같은 연락은 이 스킬이 하지 않는다. 목록까지만.
- 개설 여부나 전문의 수까지 확인이 필요하면 건강보험심사평가원 병원 찾기(hira.or.kr)에서 본다.
